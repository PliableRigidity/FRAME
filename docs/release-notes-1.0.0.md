# FRAME 1.0.0

First local release: ingestion and pairing, classical quality analysis, optional ONNX IQA adapter, duplicate/burst/scene grouping, diversity-aware collections, uncertainty review, pairwise preference profiles, safe asynchronous export, optional RAW previews, diagnostics and single-process Windows launch.

Known limits: no pretrained IQA weights or signed installer are bundled; semantic scene understanding and real-world preference calibration remain unverified.
