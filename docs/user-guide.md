# User guide

1. Launch FRAME and enter a readable photo directory.
2. Wait for scanning, thumbnails, technical scoring and similarity grouping. Cancellation is safe; rescan to resume cached work.
3. Filter KEEP/REVIEW/REJECT results and inspect explanations.
4. Open similarity groups to compare members and override their lead.
5. Set a review budget or make optional A/B preference choices.
6. Choose collection size, profile and diversity, then pin/exclude as needed and regenerate.
7. Enter a separate export directory and export. Monitor progress and inspect `frame-export-manifest.json` for hashes or failures.

FRAME never deletes, edits, or writes metadata to source photographs.
